# هینا الکتریک — صفحه به‌زودی

شاخه `main` فقط صفحه موقت «به‌زودی» را برای انتشار اصلی نگه می‌دارد.

نسخه کامل پنج‌محصولی سایت، همراه با تصاویر، محتوا، سئو و کدهای ساخت، به‌صورت دست‌نخورده در شاخه [`release`](https://github.com/Mehrdad32/heena-electric-website/tree/release) حفظ شده است.

**برای بازگرداندن سایت کامل:** از محتوای درخت `release` یک Commit جدید روی `main` بسازید؛ Merge عادی شاخه قدیمی به `main` به‌تنهایی محتوا را بازنمی‌گرداند، چون `release` نیای `main` است.

**توجه:** این مخزن Public است؛ شاخه release و تاریخچه Git برای عموم قابل مشاهده‌اند. تغییر صفحه Production به معنی خصوصی‌سازی سورس نیست.
